🛠️ SCRIPTS (EXECUTE POR ESTA ORDEM)
═══════════════════════════════════════════════════════════════════════════════

1. 💾 backup_db.sh (Backup da BD - 5 minutos)
   ├─ Executa: ./backup_db.sh
   ├─ Cria ficheiro em: ./backups/backup_simplergn_YYYYMMDD_HHMMSS.sql
   ├─ Guarde este ficheiro num local seguro!
   ├─ Exemplos: Google Drive, Dropbox, OneDrive
   └─ Tempo: 1-5 minutos

2. 🚀 sync_production.sh (SINCRONIZAÇÃO AUTOMÁTICA - 15 minutos)
   ├─ Executa: ./sync_production.sh
   ├─ O que faz:
   │  ├─ Faz backup automático
   │  ├─ Atualiza código do GitHub
   │  ├─ Reinicia containers
   │  ├─ Aplica migrations
   │  └─ Valida automaticamente
   ├─ Resultado: Sistema online com novos campos
   └─ Tempo: 10-15 minutos

3. ✓ validate_migration.sh (VALIDAÇÃO - 2 minutos)
   ├─ Executa: ./validate_migration.sh
   ├─ Verifica:
   │  ├─ Tabelas foram criadas
   │  ├─ Colunas foram adicionadas
   │  ├─ Dados preservados
   │  └─ Foreign keys ok
   └─ Usar APÓS sync_production.sh
